# F3-01 — Límites modulares y dirección de dependencias (S08)
Estado: **TESTED** (documental, 2026-10-14) · Base HEAD: af3cc74 · Auditor: Haiku read-only. Amplía docs/ARCHITECTURE.md (no lo reemplaza).

## Flujo real
Python `App.sample()` → `snapshot_json` (schema 1, ts) → stdout NDJSON 1/s → `main.js` startBackend (spawn, parseo por línea, watchdog, SIGSTOP/SIGCONT) → `webContents.send('stats')` a ventana principal y overlay → `preload.js` (onStats + 61 canales invoke ↔ 61 `ipcMain.handle`, sin desajustes) → renderer (`app.js update()` + suscriptores power.js, cores.js, widget-states.js, wizard.js) / `overlay.js`. La TUI no lee NDJSON: es un segundo presentador del mismo `App.sample()`.

## Regla de dependencias (vinculante desde S08)
- Python: collectors → `app.py` (compone y emite). Nada de presentación.
- `main.js`: ventanas, IPC, ciclo de vida. La semántica de métricas y la lógica pura van a módulos CommonJS testeables (`backend-bridge.js`, `overlay-window.js`, `priv.js`, `smart.js`, `fsutil.js`).
- Renderer: `app.js` solo compone; lógica pura en módulos UMD `window.Rog*` con test Node (procs-table, chart-editor-model, charts-catalog, fan-curve-model, widget-states, widget-status-view).
- Privilegios: solo por `priv.js` (helpers root-owned con VERSION) o `power_control.py`; no se crean rutas nuevas.

## Orden de extracción
1. charts-catalog.js (F3-02 c1) · 2. fan-curve-model.js · 3. backend-bridge.js (F3-03 c1 + F3-04) · 4. overlay-window.js junto con S10/S11 (un único módulo de geometría) · cortes pequeños: aura-color, mangohud-conf, settings-model, gpu-pending.
**No extraer**: handlers privilegiados (esperan ADR de frontera única), ventana/tray/lifecycle, modal de ventiladores (solo su matemática), UI de benchmark duplicada con bench-detail.js (decidir canónica), drawChart duplicado (unificar antes).
