## API (`window.RogProcsTable`, también `module.exports`)
| Función | Contrato |
|---|---|
| `createSortState(key, dir)` | `{key, dir}` congelado; `dir` distinto de `'asc'` => `'desc'`. |
| `toggleSort(state, key)` | Misma columna invierte; columna nueva => `'asc'` si `key==='name'`, si no `'desc'`. Devuelve estado nuevo (no muta). |
| `sortRows(rows, state)` | Copia ordenada estable (no muta; mismas referencias de fila). `name`: `localeCompare`, nombre ausente = `''`, sin desempate. Numéricas: empate => mayor `cpu` primero. `null/undefined/NaN/''` siempre al final. No-array => `[]`. |
| `colClass(key)` | `pid→pid, name→pname, cpu→cpu, cpu_core→cpu-core, mem_mb→mem`, otro => `''` (para `table.dataset.sortCol`). |
| `headerState(state, key)` | `{active, dir, arrow, ariaSort}`; activa: `dir` `'asc'\|'desc'`, `arrow` `'▲'\|'▼'`, `ariaSort` `'ascending'\|'descending'`; inactiva: `{false,'','','none'}`. |
| `formatMem(mb, unit)` | `'MiB'` (defecto) => `"N MiB"` sin redondear; `'GiB'` => `"x.xx GiB"` (`mb/1024`); no numérico => `'—'`. |

## Desviaciones deliberadas respecto a app.js actual (comportamiento por lo demás idéntico)
1. Ausentes (`null/undefined/NaN`) van **al final también en ascendente**. Hoy `null` => `-Infinity` quedaba primero en asc y `NaN` daba comparador inconsistente. En desc es idéntico a hoy.
2. `name` nulo se compara como `''` (hoy `"null"/"undefined"`).
3. `formatMem` con valor no numérico da `'—'` (hoy `"undefined MiB"` / `"NaN GiB"`).
Todo lo demás (desempate por cpu desc, `name` sin desempate, `dir` raro = desc, toggle name=asc) replica app.js.
