# F3-05 — Lifecycle suspend/resume del backend
Estado: TESTED (parcial: minimizar→reiniciar en sesión real lo valida el propietario)
Evidencia previa: ARC-03 (`desktop/main.js` startBackend hacía `kill()` a un backend en SIGSTOP; SIGTERM queda pendiente y el proceso sigue en estado T).
Cambio: startBackend envía SIGCONT antes de SIGTERM y limpia `backendPaused`.
Prueba: réplica Node con `sleep` → sin SIGCONT sigue vivo tras SIGTERM; con SIGCONT termina por SIGTERM. e2e 31/31.
Disparadores reales: guardar ajustes / actualizar con la ventana oculta o minimizada.
