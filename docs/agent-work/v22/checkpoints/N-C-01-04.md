## Decisiones de honestidad
- No se anuncia Path Tracing; overlay y benchmarks = **parciales**; Guardián 2.0 y helper único = **futuro** (decisión del propietario).
- Sensores y control de ventiladores/potencia se describen como específicos de ASUS; la capa hwmon genérica es solo lectura y «probada sobre todo en ASUS ROG».
- El bug de firmware se atribuye a «un portátil ROG» (el del mantenedor) y a «otro modelo reportado en Windows»; no se generaliza.
- `VERSION` no se toca (decisión del propietario). El README y el CHANGELOG avisan: en v22 los scripts root cambiaron sin subir `VERSION`; tras actualizar hay que ejecutar `sudo bash scripts/install-system.sh`.
- Sin capturas nuevas; el README dice en texto que `01`–`07` y el GIF son anteriores a v22.
